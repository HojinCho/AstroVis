# AstroVis
Prompted by Hojin Cho in 2026, using Claude.

An attempt to make a very lightweight viewer for FITS and CSV/TSV. Uses [Plotly.js (3.5.1)](https://github.com/plotly/plotly.js) and [fits.js](https://github.com/astrojs/fitsjs).

Use at your own risk. 

### Features
- Simple scatter plot, step-like plot, 1d and 2d histograms.
- Able to select points and examine them.
